Agent settings

The PC running Line PC Server, with its port. Short id, unique per line (letters, numbers, - or _). Sent to the API as {{LineId}}. Folder where the AOI machine writes its result files. Files are only read, never moved or deleted. Wait until the AOI has finished writing the file. Only used when the server's "only files after Start" option is off. 0 = no limit. Only the agent's own lists (Forwarded\yyyy-MM-dd.txt). AOI files are never deleted. 0 = keep forever. Restart the agent after changing.
